pcd FEATURES

PROJECT NAVIGATION

    Jump to a project by name:
        pcd <project>

    Show help (without opening the picker):
        pcd

    The interactive picker opens when a project query has multiple matches.
    Type to filter, use Up/Down to move, Enter to select, or Escape/Ctrl-C to cancel.

    Resolve a project whose name conflicts with a command:
        pcd --project <project>


PROJECT DISCOVERY

    Register the current directory as a scan root:
        pcd init

    Remove the current directory from scan roots:
        pcd uninit

    List registered scan roots:
        pcd roots

    Rescan roots, show added, removed, and total projects:
        pcd refresh

    Projects inside registered roots are discovered automatically.

    Root counts show how many discovered projects each root contributed, not how
    many canonical paths happen to be contained below it. A project is counted once
    in every root that discovered it, including overlapping roots and roots reached
    through followed symlinks. Manual projects are not counted.

    The cache records the root and display route for every discovery. When the cache
    schema changes, older snapshots are rebuilt automatically on the next read; user
    configuration is never rewritten by that migration.

    If a filesystem error prevents a root or subdirectory from being read, the scan
    is incomplete. `pcd refresh` reports the failing path and leaves the last complete
    cache snapshot in place instead of publishing partial results. Missing roots are
    still skipped and handled as unavailable locations.


MANUAL PROJECTS

    Register a directory manually:
        pcd add <path>

    Remove a manually registered project:
        pcd remove <project>


PROJECT LIST

    List all known projects:
        pcd list

    Filter by source or availability, or print JSON:
        pcd list --manual
        pcd list --discovered
        pcd list --missing
        pcd list --json


CONFIGURATION

    Print the user configuration file path:
        pcd config path

    Print, edit, or validate the user configuration:
        pcd config show
        pcd config edit
        pcd config validate

    Set `editor = "nvim"` in the configuration to choose an editor for editing.


DATA DURABILITY

    Configuration, project cache, usage history, and managed shell files are
    published with atomic replacement.

    On Linux and macOS, the containing directory is synchronized after a successful
    replacement so the new directory entry survives a crash as far as the filesystem
    supports it. Windows does not support Python directory synchronization; file
    contents are still flushed and replacement remains atomic, but the directory
    entry is not separately synchronized.

    The benchmark suite reports the extra cost of parent-directory synchronization;
    see benchmarks/README.md.


SHELL INTEGRATION

    Supported platforms: Linux, macOS, and Windows.

    Supported shells:
        Bash
        Zsh
        Fish
        PowerShell 7+
        Windows PowerShell 5.1
        Command Prompt (cmd)
        Git Bash on Windows (using the Bash integration)

    Install shell integration automatically:
        pcd shell install

    CMD installation registers an exact DOSKEY command in the current user's AutoRun
    value without changing PATH or replacing unrelated AutoRun commands.

    Check shell integration status:
        pcd shell status

    Status reports the selected shell configuration and the wrapper used for this invocation.
    `Invoked through wrapper: no` does not mean the parent shell has no wrapper installed.
    A direct call such as `command pcd shell status` bypasses the wrapper.
    The wrapper marker is scoped to its function call, not exported for the whole shell session.

    Remove shell integration:
        pcd shell uninstall

    Print shell integration code:
        pcd shell init <shell>

    Shell integration can also be added manually to the shell config.
    Version 0.2.3 removes `pcd shell print` and `pcd shell-init` and moves Python
    imports from `pcd_cli.shell_integration` to `pcd_cli.integrations.shell`.
    Old startup lines are not migrated automatically; see README.txt for replacement
    commands and reload instructions for Bash, Zsh, and Fish.
